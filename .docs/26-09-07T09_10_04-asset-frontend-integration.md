# Asset Frontend Integration

## Base API

```text
/api
```

All domain endpoints require Bearer authentication and access to PilarGroup app slug `asset`.

## Central identifiers

```text
user_id       = UUID from /auth/me.id
company_id    = string such as comp-pnm-0001
department_id = numeric department ID
```

Do not send `internal_id` as the Asset user identifier.

## Main areas

```text
Dashboard
Assets
Consumables
Depreciation
Master Data
Numbering
Permissions
Import / Export
Activity Log
```

## Asset operations

Use dedicated operation endpoints for assignment, return, transfer, maintenance, and lifecycle. Do not emulate those operations by sending field changes to ordinary asset update.

## Consumable operations

Stock is changed through movement APIs. For ISSUE, UI must capture recipient/purpose according to recipient type.

## Import UX

### Template

```http
GET /api/import/templates/:type
```

Use blob download.

### Preview

```http
POST /api/import/:type/preview
```

Multipart field:

```text
file
```

The FE should show:

- source row;
- action (`CREATE`, `UPDATE`, or movement action);
- VALID/WARNING/INVALID;
- errors/warnings;
- total/valid/warnings/invalid;
- expiry time.

Store `preview_token` only for the current preview flow. The original file is not uploaded again.

### Commit

```http
POST /api/import/commit
```

```json
{
  "preview_token": "..."
}
```

After commit, show total/success/failed and keep returned `import_reference` when navigating to Activity Log.

### Import audit navigation

Permanent import history lives in Activity Log, not in an import-history table.

To show all actions generated by one import:

```http
GET /api/activity-logs?correlation_id=<import_reference>
```

For a general list of completed import commits:

```http
GET /api/activity-logs?module=IMPORT&action=IMPORT&source=IMPORT
```

### Error download

If `error_file_token` is returned:

```http
GET /api/import/errors/:errorFileToken
```

Download as blob. The token does not represent a filesystem path.

### Cancel

```http
DELETE /api/import/preview/:previewToken
```

## Asset import update display

For existing `asset_number`, preview may show `action = UPDATE`.

After commit, Asset Activity Log entries expose meaningful changed values:

```text
old_values
new_values
source = IMPORT
correlation_id = import_reference
```

This lets FE render a change history such as:

```text
Condition: GOOD → FAIR
Vendor: 3 → 8
```

## Export UX

```http
GET /api/export/:type
```

Use blob download. Export is generated and returned in the same request.

## Activity Log

```http
GET /api/activity-logs
```

Initial filters include:

```text
module
action
user_id
entity_type
entity_id
source
correlation_id
page
limit
```

Activity Log is read-only to normal application users.
